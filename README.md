# Локальная CRM

CRM запускается на одном ПК через локальный сервер и браузер.
Рабочие данные хранятся в SQLite-файле `data/crm.sqlite`.

## Запуск

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Создать `.env.local` на основе `.env.example`.

3. Указать SMTP-настройки в `.env.local`:

   ```env
   SMTP_HOST="smtp.yandex.ru"
   SMTP_PORT="465"
   SMTP_SECURE="true"
   SMTP_USER="manager@example.com"
   SMTP_PASSWORD="YANDEX_APP_PASSWORD"
   SMTP_FROM_NAME="CRM"
   ```

4. Запустить приложение:

   ```bash
   npm run dev
   ```

5. Открыть `http://localhost:3000`.

## Проверка локального API

После запуска `npm run dev` можно выполнить быструю автоматическую проверку:

```bash
npm run test:local-api
```

Проверка создает временного клиента и договор, проверяет конфликт пересекающейся брони, создает резервную копию и удаляет временные данные.

## Проверка SMTP

После заполнения `.env.local` можно проверить доступность SMTP без отправки письма:

```bash
npm run smtp:check
```

Если проверка показывает `ECONNREFUSED` или `FAILED` для портов `465` и `587`, подключение блокируется на уровне ПК, антивируса, фаервола, роутера или провайдера. Для Яндекс Почты используйте `smtp.yandex.ru`, порт `465` с SSL или порт `587` без начального SSL.

## Данные и бэкапы

- База: `data/crm.sqlite`.
- Резервные копии: `data/backups`.
- Кнопка создания бэкапа находится в настройках, вкладка "Общие".
- Импорт из Firebase уже выполнен, Firebase-зависимости и конфиги удалены.
- Старые JSON-снимки импорта, если они есть, остаются в `data/backups` как архив.

## Шаблоны документов

- Шаблоны редактируются в настройках, вкладка "Шаблоны документов".
- Переменные вставляются в формате `{contract_number}`. В полноэкранном редакторе клик по переменной вставляет её в место курсора.
- Кнопка "Проверить" показывает неизвестные переменные и важные переменные, которых не хватает.
- Если нужный шаблон не настроен, документ не формируется по чужому шаблону.
- Перед перезаписью HTML-шаблона старая версия сохраняется в `data/backups/templates`.

## Важно

Пароль приложения Яндекса, который раньше был в исходниках, нужно считать скомпрометированным.
Создайте новый пароль приложения и храните его только в `.env.local`.
