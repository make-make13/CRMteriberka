# CRM «Большая Медведица»

Локальная CRM для гостиницы с шахматкой бронирований, гостями, договорами, задачами и локальным модулем заявок.

## Стек

- React
- Vite
- TypeScript
- Express
- SQLite
- PDFMe

## Основные разделы

- Шахматка
- Заявки
- Гости
- Договоры
- Дополнительно
- Настройки

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```

## Что не хранится в Git

- `.env.local`
- SQLite-база
- backups
- `node_modules`
- `dist`
- logs
