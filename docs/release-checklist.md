# Release checklist 0.1.0 — CRM «Большая Медведица»

Практический чеклист перед выдачей Windows installer менеджеру.

---

## Перед сборкой

- `git status --short` не показывает незакоммиченные изменения, кроме осознанных release docs.
- Версия в `package.json` соответствует релизу: `0.1.0`.
- Не менялись бизнес-логика CRM, договоры, DOCX/PDF генерация, шаблоны, Supabase schema, сайт и ИИ-консьерж.
- `npm run build` проходит.
- `npm run build:server` проходит.
- `npm run build:electron` проходит.
- `npm run electron:pack` проходит.
- `npm run electron:installer` проходит.

---

## Сборка

Рекомендуемый набор команд:

```powershell
$env:ELECTRON_CACHE = "D:\Temp\electron-cache"
$env:electron_config_cache = "D:\Temp\electron-cache"

npm run build
npm run build:server
npm run build:electron
npm run electron:installer
```

Если нужен только unpacked build:

```powershell
$env:ELECTRON_CACHE = "D:\Temp\electron-cache"
npm run electron:pack
```

---

## Проверка installer

Проверить артефакты в `release/`:

- `Большая-Медведица-CRM-Setup-0.1.0.exe` существует.
- Размер installer записан в release report.
- `Большая-Медведица-CRM-Setup-0.1.0.exe.blockmap` существует.
- `latest.yml` существует и указывает на текущую версию `0.1.0`.
- `release/win-unpacked/` существует.
- `release/win-unpacked/Большая Медведица CRM.exe` существует.

Проверить установку:

- Setup.exe запускается.
- Установка выполняется для текущего пользователя.
- Название приложения: `Большая Медведица CRM`.
- Создаётся ярлык на рабочем столе.
- Создаётся ярлык в меню «Пуск».
- Иконка отображается.
- Приложение запускается из ярлыка.
- Backend стартует.
- `/api/health` отвечает `{"ok":true}`.
- `/api/app-info` отвечает.
- `dataDir` указывает на `%APPDATA%\Большая Медведица CRM`.
- Login `Make / 3552` работает.
- Рабочая база проекта `data/crm.sqlite` не изменена.

## Проверка CRM

### Шахматка

- Раздел открывается.
- Номера и даты отображаются.
- Нет ошибок в консоли.

### Заявки

- Раздел открывается.
- Кнопка «Проверить заявки» работает.
- Повторная проверка не создаёт дубли.
- Заявки из AI/сайта отображаются с понятным источником.
- Тестовая заявка, если создаётся, помечается как `Тест RC`.

### Гости

- Раздел открывается.
- Можно открыть карточку гостя.
- Создание гостя из заявки работает на тестовой записи.

### Договоры

- Раздел открывается.
- Список договоров отображается.
- Проверка не должна менять шаблоны или генерацию договоров.

### Настройки → Система

- Версия `0.1.0`.
- Mode `production` в установленной программе.
- `dataDir` и `dbPath` указывают на AppData.
- Блок «Первый запуск» отображается.
- Supabase status отображается без раскрытия ключей.
- LibreOffice status отображается.
- ИИ-консьерж может быть «не настроен» без ошибки.

### Настройки → Интеграции

- Supabase URL отображается только как обычная настройка.
- Service Role Key не раскрывается, показывается только маска.
- «Проверить подключение» для Supabase работает.
- LibreOffice находится или выводит понятную ошибку.
- Автосинхронизация заявок по умолчанию выключена.
- Автосинхронизацию можно включить и выключить обратно.
- `/api/leads/auto-sync/status` показывает корректное состояние.

### Backup

- Вкладка резервных копий открывается.
- Состояние backup отображается без runtime crash.
- Ручной backup выполняется только если это безопасно для текущей проверки.

### Supabase sync / Auto-sync

- Ручная синхронизация работает.
- Автосинхронизация по умолчанию выключена.
- После включения статус планировщика меняется.
- После выключения статус возвращается в выключенное состояние.

---

## Что пока НЕ считается блокером

- Нет code signing.
- Нет auto-update.
- Нет bundled LibreOffice installer.
- Нет автоматического переноса старой базы.
- Большой размер installer.
- Vite предупреждает о крупных PDFMe chunks.
- electron-builder предупреждает, что `asar` выключен.
- `latest.yml` создаётся как metadata на будущее, но auto-update сейчас не используется.

---

## Что является блокером

- Приложение не запускается.
- Backend не стартует.
- `/api/health` не отвечает.
- SQLite не открывается.
- Login не работает.
- Supabase Service Role Key раскрывается во frontend.
- Рабочая база проекта `data/crm.sqlite` повреждена или изменена установщиком.
- PDF генерация полностью сломана.
- Установленная программа требует системный Node.js для packaged backend.
