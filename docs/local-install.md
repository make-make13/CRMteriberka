# Локальная установка CRM «Большая Медведица»

CRM работает как **локальная программа** на компьютере менеджера или на сервере гостиницы.
Все данные хранятся локально (SQLite), интернет нужен только для синхронизации
входящих заявок из Supabase.

---

## Что нужно для работы

### 1. Node.js

- Версия: **18 или новее**
- Скачать: [nodejs.org](https://nodejs.org/)

После установки проверить:
```
node -v
npm -v
```

### 2. LibreOffice

Нужен для конвертации договоров из DOCX в PDF прямо на компьютере.

- Скачать: [libreoffice.org/download](https://www.libreoffice.org/download/download/)
- Установить в стандартный путь — CRM найдёт его автоматически:
  ```
  C:\Program Files\LibreOffice\
  ```

После установки LibreOffice **перезапустите CRM**.

#### Нестандартный путь установки

Если LibreOffice установлен в другую папку, укажите путь в настройках CRM:
**Настройки → Интеграции → LibreOffice** — поле «Путь к soffice.exe».

Альтернативно — через `.env.local`:
```env
LIBREOFFICE_PATH=C:\МойПуть\LibreOffice\program\soffice.exe
```

#### Порядок поиска LibreOffice

1. Настройки CRM (Настройки → Интеграции)
2. `LIBREOFFICE_PATH` из `.env.local`
3. `C:\Program Files\LibreOffice\program\soffice.exe`
4. `C:\Program Files (x86)\LibreOffice\program\soffice.exe`
5. `soffice.exe` в системном PATH

## Структура папок

```
<папка CRM>/              ← код программы (обновляется при обновлении)
  server.ts               ← точка входа сервера
  dist/                   ← собранный frontend (создаётся npm run build)
  data/                   ← ДАННЫЕ (не трогать при обновлении!)
    crm.sqlite            ← база данных (гости, договоры, заявки)
    backups/              ← автоматические резервные копии
      before-migration-*/ ← backup перед структурными миграциями БД
  storage/                ← ФАЙЛЫ ПОЛЬЗОВАТЕЛЯ (не трогать при обновлении!)
    docx-templates/       ← шаблоны договоров DOCX
  .env.local              ← локальные настройки (не трогать при обновлении!)
```

> **Правило**: при обновлении CRM обновляется **только код** (файлы проекта кроме data/,
> storage/, .env.local). Данные никогда не перезаписываются автоматически.

## Переменные окружения для расположения данных

По умолчанию данные хранятся рядом с кодом CRM в папке `data/`.
Если нужно хранить данные отдельно от кода (рекомендуется для продакшна):

| Переменная     | Что задаёт                                     | Пример                        |
|----------------|------------------------------------------------|-------------------------------|
| `CRM_DATA_DIR` | Корневая папка данных (БД + backups)           | `D:\CRM-data\`                |
| `CRM_DB_PATH`  | Явный путь к файлу базы данных                 | `D:\CRM-data\crm.sqlite`      |

Логика приоритетов:
1. `CRM_DB_PATH` — явный путь к БД (наивысший приоритет)
2. `CRM_DATA_DIR` — БД находится внутри: `CRM_DATA_DIR\crm.sqlite`
3. По умолчанию: `<папка CRM>\data\crm.sqlite`

Резервные копии всегда хранятся в `CRM_DATA_DIR\backups\` (или `data\backups\` по умолчанию).

Задавать в `.env.local`:
```env
CRM_DATA_DIR=D:\CRM-data
```

## Настройки интеграций через UI

Все интеграции настраиваются **через интерфейс CRM** — нет необходимости
редактировать `.env.local` вручную:

**Настройки → Интеграции**:
- **Supabase** — URL проекта, service role key, имя таблицы, лимит синхронизации
- **LibreOffice** — путь к `soffice.exe`
- **AI-бэкенд** — URL и ключ внешнего AI-консьержа (будущее)

Секреты (ключи) хранятся в SQLite, не покидают сервер. В UI отображается
только маска последних 4 символов.

`.env.local` остаётся как fallback для dev-режима и для первоначальной настройки.

## Первый запуск (ручная установка)

### 1. Получить код CRM

```
git clone <repo> crm
cd crm
```

Или распаковать архив с кодом.

### 2. Установить зависимости

```
npm install
```

### 3. Собрать frontend

```
npm run build
```

### 4. Настроить `.env.local`

```
cp .env.example .env.local
```

Обязательные поля:
```env
# SMTP (для отправки документов по email):
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=manager@example.com
SMTP_PASSWORD=...
```

Опциональные:
```env
# Порт сервера (по умолчанию 3002):
PORT=3002

# Папка данных (по умолчанию ./data/):
# CRM_DATA_DIR=D:\CRM-data

# Supabase (можно настроить через UI):
# SUPABASE_URL=https://xxxxxxxxxx.supabase.co
# SUPABASE_SERVICE_ROLE_KEY=sb_secret_...
```

### 5. Запустить CRM

**Через bat-файл (рекомендуется):**
```
start-crm.cmd
```

**Через npm:**
```
npm run start
```

Открыть в браузере: `http://localhost:3002`

## Dev-режим (для разработчиков)

```
npm run dev
```

Открыть: `http://localhost:3002`

В dev-режиме работает Vite HMR (горячая перезагрузка). `npm run build` не нужен.

## Архитектура

```
[Сайт БМ] → [Supabase (входящий ящик заявок)] ← CRM забирает кнопкой "Проверить заявки"
                                                          │
                                                  [data/crm.sqlite]
                                                          │
                                               CRM генерирует договоры
                                               DOCX/PDF через LibreOffice
                                               (локально, без облака)
```

- **SQLite**: вся информация (гости, договоры, заявки, настройки) — локально
- **Supabase**: только входящий ящик заявок с сайта
- **LibreOffice**: конвертация DOCX→PDF на машине менеджера
- **Интернет**: нужен только для синхронизации заявок

## Резервное копирование

### Ручное
Скопируйте файл `data/crm.sqlite` — это вся база данных.

### Автоматические копии
Хранятся в `data/backups/`. Создаются:
- Перед структурными изменениями схемы БД (папка `before-migration-YYYY-MM-DD-HH-mm-ss/`)
- Через функцию резервного копирования в настройках CRM

### Что важно сохранить при обновлении
| Что                        | Где                     |
|----------------------------|-------------------------|
| База данных                | `data/crm.sqlite`       |
| Резервные копии            | `data/backups/`         |
| Шаблоны договоров          | `storage/`              |
| Настройки окружения        | `.env.local`            |

- ✅ При обновлении заменит только код, не данные

Пока установщика нет — следуйте шагам выше вручную.
