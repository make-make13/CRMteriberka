# Первый запуск CRM «Большая Медведица»

Документ описывает минимальные действия после установки CRM через Windows Setup.exe.
Цель — подготовить программу к работе менеджера без изменения бизнес-логики,
базы данных, договоров или шаблонов.

---

## 1. Установка через Setup.exe

1. Запустите файл установщика:

   ```text
   Большая-Медведица-CRM-Setup-0.1.0.exe
   ```

2. Следуйте стандартным шагам установщика Windows.
3. Если Windows SmartScreen предупреждает о неизвестном издателе, это ожидаемо:
   code signing пока не настроен.
4. После установки CRM будет доступна как обычная программа Windows.

---

## 2. Где запускается программа

После установки CRM запускается из меню «Пуск» Windows или из папки установленной
программы:

```text
C:\Users\<пользователь>\AppData\Local\Programs\bolshaya-medveditsa-crm
```

Backend запускается внутри Electron-приложения. Отдельный системный Node.js для
установленной версии не требуется.

---

## 3. Где хранятся данные

Рабочие данные установленной CRM хранятся в профиле пользователя Windows:

```text
AppData/Roaming/Большая Медведица CRM
```

В этой папке находится рабочая SQLite-база и служебные данные приложения.
Не удаляйте эту папку без резервной копии.

---

## 4. Что настроить после первого запуска

Откройте CRM и проверьте настройки в таком порядке.

### Настройки → Интеграции → Supabase

Укажите:

- Supabase URL;
- Service Role Key;
- имя таблицы заявок, обычно `leads`;
- лимит синхронизации.

После заполнения нажмите «Проверить подключение».

### Настройки → Интеграции → LibreOffice

LibreOffice нужен для конвертации договоров DOCX в PDF.

1. Если LibreOffice установлен в стандартный путь, нажмите «Найти автоматически».
2. Если путь не найден, укажите полный путь к `soffice.exe`, например:

   ```text
   C:\Program Files\LibreOffice\program\soffice.exe
   ```

3. Нажмите «Проверить LibreOffice».

### Настройки → Интеграции → Автопроверка заявок

Автоматическая проверка заявок из Supabase по умолчанию выключена.

Если нужно, включите «Автоматическая проверка заявок», выберите интервал и
сохраните настройки. Рекомендуемый начальный интервал — 5 минут.

### Настройки → Система

Проверьте:

- версию CRM;
- режим запуска;
- папку данных;
- путь к базе данных;
- состояние Supabase и LibreOffice.

### Резервные копии

После настройки интеграций сделайте резервную копию. Это фиксирует рабочее
стартовое состояние перед реальным использованием.

---

## 5. Как проверить заявки

### Вручную

Откройте раздел «Заявки» и нажмите кнопку «Проверить заявки».
CRM заберёт новые записи из Supabase и сохранит их в локальную базу.

### Автоматически

Откройте «Настройки → Интеграции → Supabase», включите автоматическую проверку
заявок, выберите интервал и сохраните настройки.

Статус планировщика отображается в этой же секции: последний запуск, последний
успех, количество полученных заявок и последняя ошибка, если она была.

---

## 6. Если LibreOffice не найден

1. Установите LibreOffice с официального сайта.
2. Используйте стандартный путь установки:

   ```text
   C:\Program Files\LibreOffice
   ```

3. Перезапустите CRM.
4. Откройте «Настройки → Интеграции → LibreOffice».
5. Нажмите «Найти автоматически» и затем «Проверить LibreOffice».
6. Если автопоиск не помог, укажите путь к `soffice.exe` вручную.

Пока LibreOffice не найден, работа CRM возможна, но конвертация договоров DOCX
в PDF будет недоступна.

---

## 7. Если Supabase не подключается

Проверьте:

- Supabase URL указан полностью и начинается с `https://`;
- Service Role Key введён в настройках CRM;
- имя таблицы заявок совпадает с таблицей в Supabase;
- есть доступ к интернету;
- Supabase-проект доступен и не остановлен.

После исправления настроек нажмите «Проверить подключение».

Не вставляйте Service Role Key во frontend-код и не создавайте переменную
`VITE_SUPABASE_SERVICE_ROLE_KEY`.

---

## 8. Что пока не реализовано

В текущем установщике намеренно не реализованы:

- перенос старой рабочей базы;
- auto-update программы;
- установка LibreOffice галочкой в установщике;
- code signing.

Эти действия требуют отдельного плана и отдельного подтверждения.
