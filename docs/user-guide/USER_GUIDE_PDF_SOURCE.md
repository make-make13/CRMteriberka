## Страница 2. Установка программы

![Окно установщика](./screenshots/01-installer-start.png)

```text
Скриншот добавить после финальной установки.
```

CRM устанавливается через файл:

```text
Bolshaya-Medveditsa-CRM-Setup-0.1.0.exe
```

Что показать на скриншоте:

- где находится файл установщика;
- куда нажать для запуска установки;
- как выглядит окно установщика;
- что делать, если Windows показывает предупреждение безопасности.

Подписи для скриншота:

- «1. Запустите установщик»
- «2. Подтвердите запуск»
- «3. Дождитесь завершения установки»

Действия пользователя:

1. Найдите файл установщика.
2. Откройте его двойным щелчком.
3. Если Windows показывает предупреждение, подтвердите запуск только если файл получен от администратора.
4. Дождитесь завершения установки.

## Страница 8. Обработка заявки

![Карточка заявки](./screenshots/07-lead-card.png)

```text
Скриншот добавить после финальной установки.
```

В карточке заявки менеджер проверяет данные гостя и решает, что делать дальше.

Возможные действия:

- подтвердить заявку;

- отклонить заявку;
- создать гостя из заявки;

Действия пользователя:

1. Откройте заявку.
2. Проверьте имя, телефон и даты.
3. Прочитайте комментарий гостя.
4. Выберите нужное действие.
5. Сохраните результат.

## Страница 18. Частые проблемы

### Программа не открывается

Что сделать:

1. Закройте программу.
2. Запустите её заново.
3. Если ошибка повторяется, сообщите администратору.

### Не проходит вход

Что сделать:

1. Проверьте логин.
2. Проверьте пароль.
3. Проверьте раскладку клавиатуры.
4. Обратитесь к администратору.

### Не видно заявки

Что сделать:

1. Откройте раздел «Заявки».
2. Проверьте фильтры.
3. Нажмите ручную синхронизацию, если такая кнопка есть.
4. Обратитесь к администратору.

### Не формируется документ

Что сделать:

1. Проверьте, заполнен ли договор.
2. Попробуйте сформировать документ ещё раз.
3. Обратитесь к администратору.

### Данные пропали

Что сделать:

1. Не удаляйте служебную папку данных программы.
2. Не переустанавливайте программу повторно без администратора.
3. Обратитесь к администратору.
