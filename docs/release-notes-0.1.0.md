# Release notes 0.1.0 — CRM «Большая Медведица»

Версия `0.1.0` — первый практический release candidate локальной CRM для работы
менеджера гостиницы на Windows.

---

## Что входит в 0.1.0

- Electron desktop app для Windows.
- NSIS Setup.exe draft/RC.
- Packaged backend через Electron runtime без системного Node.js.
- Локальная SQLite-база в AppData пользователя.
- Интерфейс CRM:
  - Шахматка;
  - Заявки;
  - Гости;
  - Договоры;
  - Дополнительно;
  - Настройки.
- Supabase sync для входящих заявок.
- Автоматическая синхронизация заявок, по умолчанию выключена.
- Вкладка «Настройки → Интеграции».
- Вкладка «Настройки → Система».
- First-run guide и системная подсказка первого запуска.
- App identity: имя и иконка приложения.

---

## Что уже работает

- Установка через `Большая-Медведица-CRM-Setup-0.1.0.exe`.
- Запуск CRM как обычной Windows-программы.
- Backend стартует вместе с Electron-приложением.
- `/api/health` и `/api/app-info` доступны после запуска.
- Login менеджера работает.
- Данные установленной CRM хранятся в:

  ```text
  AppData/Roaming/Большая Медведица CRM
  ```

- Supabase можно настроить через UI.
- Service Role Key не раскрывается во frontend и отображается только маской.
- Заявки можно проверять вручную кнопкой «Проверить заявки».
- Автопроверку заявок можно включить в настройках.
- LibreOffice можно найти автоматически или указать путь к `soffice.exe`.
- Вкладка «Система» показывает версию, режим, папку данных и состояние интеграций.

---

## Как установить

1. Запустить:

   ```text
   release/Большая-Медведица-CRM-Setup-0.1.0.exe
   ```

2. Установить приложение для текущего пользователя.
3. Запустить «Большая Медведица CRM» из меню «Пуск» или с рабочего стола.
4. Войти в CRM.

---

## Что настроить после установки

Откройте «Настройки → Интеграции»:

- Supabase URL;
- Supabase Service Role Key;
- таблицу заявок, обычно `leads`;
- LibreOffice path, если автопоиск не нашёл `soffice.exe`;
- автопроверку заявок, если она нужна менеджеру.

Откройте «Настройки → Система»:

- проверьте `version = 0.1.0`;
- проверьте `mode = production`;
- проверьте путь к папке данных;
- нажмите проверки Supabase/LibreOffice при необходимости.

После настройки сделайте резервную копию.

## Известные ограничения

- Installer пока без code signing, поэтому Windows SmartScreen может показывать предупреждение.
- Auto-update не реализован и не должен включаться без отдельного плана.
- LibreOffice не устанавливается галочкой внутри installer.
- Автоматический перенос старой рабочей базы не реализован.
- Размер installer большой.
- `latest.yml` и `.blockmap` создаются как metadata electron-builder, но auto-update сейчас не используется.
- Vite может предупреждать о больших PDFMe chunks.
- `asar` пока выключен, потому что сборка оставлена в максимально прозрачном RC-режиме.
